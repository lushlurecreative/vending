# Venegas Vending

Marketing site for **Venegas Vending** — premium snack and specialty vending machine placement across the DFW area.

**Site:** [venegasvending.com](https://venegasvending.com)  
**Contact:** [Elizabeth@venegasvending.com](mailto:Elizabeth@venegasvending.com)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Static output lands in `dist/` — deploy that folder to any static host (Netlify, Vercel, Cloudflare Pages, or your domain’s web root).
